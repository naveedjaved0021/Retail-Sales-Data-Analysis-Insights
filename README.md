Retail Sales Data Analysis
Project Overview
This project examines retail sales transaction data using Python to highlight sales trends, top-performing products, customer purchasing patterns, store performance, and payment method preferences.
Dataset
•	Records: 50,783 transactions
•	Columns: 16
•	Missing values: 0 reported in the initial inspection
•	Duplicate rows: 0 reported in the initial inspection
The dataset includes transaction timestamps, product details, quantities, prices, total amounts, stores, payment methods, and customer types.
Tools and Technologies
•	Python
•	Anaconda
•	Jupyter Notebook
•	Pandas
•	Matplotlib
Project Workflow
1.	Load the CSV dataset.
2.	Inspect dataset structure and data quality.
3.	Check missing values and duplicate records.
4.	Analyze overall sales performance.
5.	Explore monthly sales trends.
6.	Compare products, stores, customer types, and payment methods.
7.	Create visualizations and export analysis results.
